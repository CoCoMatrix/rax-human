# C-0.2：抓取与放置朝向解耦

保留 C-0.1、B 系列和既有冻结版本。生产执行仍使用原 KDL 与原接口，不启用 TRAC-IK。

本轮 20261113-132643 初始定位成功，但旧预检在 90 秒超时。Orange 位于约 X395/Y−209 mm；可用接近朝向直接沿用到并排放置时，指尖与红块发生约16.5mm的模型重叠。扩大IK预算不能修复这一几何冲突。

新版本先复用已验证的拾取前缀，再搜索保持方块竖直的四种对称放置朝向。同朝向优先，其次±90°及180°；不使用任意倾斜或免碰撞转向。转向沿原有搬运路径规划，负载角点仍绑定抓取法兰，原生FCL、桌面、指尖、载荷、工作区及衔接曲线全部检查。红橙左右可交换、绿色仍在红色上，目标结构与方向保持。

放置状态估计同步使用闭爪时实测的完整刚体变换和负载角点；转向后不能只用法兰位置差估算积木位置。旧的固定朝向演练记录继续兼容。

50% SDK、50mm抓取目标、48–54mm实测范围、原间距/误差允许、闭爪和释放边界保持。没有新增强制模型调用或观测。

对同一1183个实测IK请求，KDL与TRAC-IK Speed/Distance均成功988个，Speed未挽救任何KDL失败请求。旧规划器使用TRAC-IK仍90秒超时；朝向修复后两者约12.2秒通过。因此本次不替换在线求解器。完整结果见TRAC-IK-COMPARISON.json，回归与实际原生曲线检查见OFFLINE-VALIDATION.json。本版尚未真机验收。
