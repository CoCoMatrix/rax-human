# R7 演练后的工程修复（Mac Codex，离线）

来源是 RAX R7 软件收尾提交 `2101a65c71618fa902101452b9e2496c67dd2262`。
当前目录是独立可写候选，不改 R3 冻结版本，不改原 R7 回执和收尾。
本次没有连接机器人、采集新图像、发送运动或调用真实模型。

## 几何冲突与摆放余量

60 mm 是积木的近似尺寸，不等于夹住它时指尖也能在相同间距下避开邻块。
R7 的 60 mm 中心间距，终点一根指尖的基座轴对齐包络与红块包络重叠约 0.57 mm；
这说明模型预检冲突，不是实物已碰撞。当前夹爪朝向、指尖横向尺寸和保守包络都会影响结果。
原碰撞包络没有缩小，原 60 mm 冲突回放仍拒绝。

新增只读函数 `plan_base_placement(ctx, previous_report, quaternion, ...)`：

- 在 60–75 mm 中心间距内选候选，默认优先 65 mm，步长 2.5 mm。
- 横移、下降、上退逐段检查完整 IK、原生 CAD／工作区，以及 41 个 FK 样点。
- 候选要求至少 3 mm 指尖／红块名义余量；桌面、其他积木和控制约束保留。
- 输出本轮的横移点、下降点、上退点和拒绝原因，不自动执行或重试运动。
- R7 保存状态的离线真实求解选中 65 mm，整条路径最小名义指尖／红块间隙约 4.46 mm。

调用顺序：验证抬高后的 `transport` → `plan_base_placement` → 主 Agent 查看候选 →
用返回的当前场景点分别演练 `transport`、`lower_to_support`、`release`、`retreat`。
这是任务内有界选点，不是拼接轨迹或无 Agent 的 `main(ctx)`。
头部外参仍是暂定标定，以上数值不代表实测碰撞精度。

## 三维目标、观察位与绿色入口

`history_scene.released_scene` 读取完成且连续的释放、退开和空载观察位回执：

- 红、绿未被操作，保留本轮测量来源、坐标和标定；接近微弱磁吸物体本身不自动使坐标失效。
- 橙块已搬动，利用原抓取关系和实际放置关节反馈更新坐标，标为 `action_derived`，不称为新深度测量。
- 明显的当前画面位置矛盾、用户显式失效、所有权／标定改变、插入动作、缺失回执会阻止复用。
- 场景测量来源与新接近的状态起点分开。绿色后续接近从本次实际起点衔接，不再与最初拍照时的关节姿态比较。

`empty_inspection` 使用这份场景的桌面和物体高度包络检查空载路径；不再要求先看全三块才能移动到观察位。
`green_pregrasp` 不再强制重测红、橙两块；其高位预抓取范围允许距离绿色中心 12 mm 内、
法兰在块顶上方 180–240 mm、单步 120 mm 内，仍必须通过实际 IK／路径／全指尖检查。
这些是高位接近余量，不是允许带偏差闭合或下降穿过物体。

## 视觉与腕部深度

- 旧模板相关分数、边界斜率只作诊断；删除放置、释放、退开路径对固定模板及宽度比例的依赖。
- 保留可见物体和夹指的大体相对关系；无完整轮廓不自动等于失败。明显滑移、倾倒、目标丢失仍返回检查。
- 支撑和退开使用跨头部／左腕的定性判断，不要求证明隐藏底面、精确像素面积或两帧间绝无瞬间接触。
- 正常结束和 `verify_completed_action` 的退开恢复走同一判断，不再落入已停用的旧 helper。
- 判断不足且头部受遮挡时，允许一次原生 `piper_observe(depth_cameras=['left'], require_depth=False)`。
  用这份腕部图像自己的有效深度区域取点，查询 `output_frame='camera_optical'`。
  不用旧像素查询新深度，不填洞，不把未做手眼标定的腕部点变成基座运动目标。
- 可选腕部采样期间若关节、所有权或标定改变，该变化不会被“辅助深度不可用”掩盖。

后端 RGB 观测现在也提供当前关节／夹爪开度下的指尖几何，与实际碰撞使用同一个安装包络。
加载几何不需要头部 FFS，所以搬运、放置、退开和观察位入口不再为此强制等深度。
首次定位仍需要有效头部深度；该要求未删除。

## 验证与下一步

当前离线回归覆盖保存图像、深度空洞、回执连续性、只读恢复、光学坐标契约和反例；
另用真实但纯只读的 FK／MoveIt IK／碰撞模块回放观察位、绿色入口、摆放候选。
任何硬件接口在离线验证中均被拒绝或替换为显式假接口。
验证结果与文件散列在工作区 `output/repair/`，服务器
`verification/magnetic-blocks-r7-repair/`，Mac `outputs/rax-blocks-r7-repair/`。

本次未实现绿色最终堆叠函数，也未证明整段无人执行或跨摆位泛化。
R7 最终 SSE 超时及主模型长等待未因这些离线控制修复得到网络层验证；不能把上述路径耗时当成整轮耗时。
