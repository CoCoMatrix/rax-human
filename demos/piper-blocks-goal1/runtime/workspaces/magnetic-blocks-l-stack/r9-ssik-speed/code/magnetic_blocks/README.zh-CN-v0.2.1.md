## 本次实现

- 支撑判断改为大体对齐、直立、无明显悬空/滑落/倾斜；允许小偏差、遮挡与透视变化，不要求看见隐藏底面或证明接触力。必要时仍用 Gemini 看头部和腕部视图。
- 下降结果已经通过时，松爪前可复用该判断：同一个完成动作端点、Owner/标定/几何/姿态保持一致，30 秒内，两路新图像没有明显局部变化。检测的是“是否变化”，不是用像素面积衡量摆放精度。
- 负面、未知、缺图、时间过长或画面变化不会自动转为通过；会回到一次当前定性判断。原动作回执、场景绑定、IK、CAD/载荷/桌面检查仍有效。
- 定性视觉不再仅因头部遮挡就强制等待新的腕部 FFS。已有的绑定腕部深度仍可作为辅助；需要度量定位时仍走深度工具。未标手眼的腕部光学点不变成 base 目标。
- 绿色第一次低处绕行和第二次抬高保留；之后两段同高度横移合成一次到目标上方的移动。任务层横移上限与已有单次 400 mm 上限一致，合并后重新做 IK、原生路径检查及载荷/邻块采样；较长路径增加采样点，保持原采样密度。失败停止，不盲目改道或重试。

不是连续轨迹 blending；闭爪、试抬、支撑、释放、退开仍有结果边界。橙块接触下降和改变朝向的过渡没有合并。速度、夹爪目标和关节容差没有改动。

## 验证与限制

全量离线测试 129 项通过，包含同端点复用、双视角变化、负面/未知/旧证据拒用、释放接口消费复用、变化后负面兜底不被覆盖、合并长路径的碰撞/中途载荷检查。

R8 历史原始图像回放：橙块下降至释放相隔 22.83 秒，能复用并省一次 Gemini；绿色相隔 36.39 秒，超出 30 秒窗口，仍需判断。回放显式关闭墙钟新鲜度验证但不改原时间戳，绝不把这些旧图作为实时观测。还没有用真实 Gemini 重新评估新提示词的效果。

正常快速链路中可望减少两次重复支撑询问，但实际调用次数取决于新图变化和等待；下降支撑与最终退开仍可能调用辅助视觉，不承诺零次。高处横移减少一次动作 RPC、一次阶段入口与重复输入计算；实际速度收益和合并长路径在真机上的可达性尚未测试。
