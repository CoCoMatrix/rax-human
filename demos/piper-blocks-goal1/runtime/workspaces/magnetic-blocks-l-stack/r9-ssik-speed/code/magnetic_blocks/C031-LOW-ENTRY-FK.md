# C-0.3.1：低位入场与本地纯FK

独立离线候选，保留C-0.3以及此前全部版本。没有改任务顺序、布局排序、间隙、KDL预算、速度、抓取或到位/跟随容差；没有启动硬件动作或切换现有Prepare。

## 低位入场
对于已经朝下的空载夹爪，低位接近新增内侧较高入场点，可先避开底座，再斜向接近或下降后沿手指长轴接近。用实际指尖形状、邻近块高度和当前位姿生成两个有限候选；原直达优先、原有路线保留作后备，仅去除完全重复候选。所有候选继续经过原采样几何、完整任务原生检查和实际衔接曲线检查。
保留从Prepare旋转进入任务的原路线。初稿在一个既有摆位增加了预计运动时间，因此没有发布；最终限制新候选的适用情况，并重新回归。

## 纯FK开销
复用 services.piper.geometry.Kinematics 和其固定URDF，不另写DH或修改几何。每个ctx启用前，通过1次piper_fk_batch核对URDF SHA、基座/法兰坐标、5组姿态矩阵；不一致直接拒绝，不静默接受。缺少本地模块时退回原服务计算。单点与批量共享精确关节键，不量化；保留全部采样、右臂不动检查及原关节限制。采样只算矩阵，端点需要时再算四元数。
几何和IK仍使用原语义；原生碰撞服务、状态绑定、动作反馈与Stop都保留。几何模块及URDF哈希加入候选宿主契约，新纯FK文件加入运行源码记录。

## 验证范围
406项回归、52项子测试；1027组随机合法关节位姿的本地/原生单点FK矩阵对照；模型/坐标/数据不一致、关节越限与ctx一次校验测试。18组完整规划和衔接曲线检查，不以离线通过代替真机成功率。
本轮141435旧线上90s超时、旧代码离线约54.7s。最终重点回放预检约6.9s，FK只1次服务端批量校验。附加4ms/RPC的延迟回放见报告，模拟开销并非实际在线时延承诺。
动作时长另用原生轨迹编译器估算；该计算不作为碰撞批准。执行速度50%、持稳及闭爪策略等保持原配置。详见MOTION-TIMING-FINAL.json、coverage-final、REGRESSION-FINAL.txt。
