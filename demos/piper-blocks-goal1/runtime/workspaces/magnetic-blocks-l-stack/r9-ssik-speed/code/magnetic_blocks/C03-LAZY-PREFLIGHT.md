# C-0.3：完整候选先筛几何，后做原生检查

保留 RAX main(ctx)、Piper 接口、KDL、短预算优先/失败长预算补查；没有添加规划框架。
参考 OMPL LazyPRM 的延迟昂贵有效性检查策略：先构成完整任务候选并检查指尖/载荷/桌面/工作区的几何采样，再原生检查全部动作。原生拒绝的精确边被缓存；清除包含它的派生路径并在原预算内重新搜索。无完整原生证明不能返回可执行计划。速度衔接后的曲线仍独立做原生预览与几何检查。
来源：https://github.com/ompl/ompl/blob/main/src/ompl/geometric/planners/prm/src/LazyPRM.cpp

删除接近搜索额外1mm硬门槛。规划和执行共用原最低间距：指尖名义3mm/允许0.5mm偏差、负载自由路径名义20mm/允许0.5mm偏差。额外余量只用于优选，有效候选不会因不足优选值丢弃。桌面、自碰撞、工作区、关节限位及其他已有阶段约束未放宽。
完整规划与几何拒绝、IK无解、原生碰撞、预算耗尽、连接中断、I/O及取消分开报告，不再把ConnectionError归为缺少视觉证据。动作下发后通信结果不明仍停止并要求核对；不自动重放动作。

离线：397项测试、52项子测试；17组布局（6种非共线颜色排列、2组散放布局、9组历史场景）完整规划与衔接曲线/原生分段回退全部通过。额外注入一条原生路径拒绝后重新搜索通过；全部短预算IK拒绝后真实长预算KDL补查通过。禁止owner及socket访问，硬件下发0。
