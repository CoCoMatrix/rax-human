# B-0.7 数值边界核对与修复

适用范围：当前积木合并版 `assembly_controller.main(ctx)` 及它实际调用的规划、执行和定性判断；保留 B-0.6、原 main、冻结版本。历史逐函数演练入口未批量改写，不把这些门槛当成当前 main 的限制。

## 本轮停止原因

运行 `web-main-20261113-105847-ab17b4`：预检16.415秒通过，绿色已完成下降和释放；`green-retreat-16` 的动作下发前检查失败，未发出该退开动作。拒绝对象是 `left_gripper_link2` 与 `environment:green`，原生 FCL 距离2.977777mm，小于原3mm阈值。上版只调整了任务AABB门槛，原生检查未同步。

本次对完整实际路径离线复测：原规则在第18/52个原生采样点拒绝；新规则52点全部通过，允许区间内的最小模型距离2.796455mm。任务层另检查252个样本，也通过。均未发出硬件动作。

## 审查后保留的门槛

- URDF关节限位、法兰工作区、400mm单段/60°关节段、速度/加速度、停止授权：控制与硬件边界，保持。目标附近可寻找其他经检查的路径，不用误差名义越界。
- 关节到位/绑定0.01rad、夹爪绑定0.5mm、夹持48–54mm：已经有明确容差，且与原生回执契约配对；不继续叠加。
- 手指/桌面12mm及初始标定余量、载荷桌面穿透/支撑容差、负载接触1mm下限：保持已有非穿透及接触规则。
- 采样完整性、有限数值、维度、单位、模型SHA/owner代际、回执身份、缓存精确键：数据契约，不能按空间误差放宽。
- 图像/状态新鲜度、30/90秒搜索预算、停止超时：时间语义；不以几何误差延长。
- HSV分割、最小可辨认像素、深度有效点、桌面拟合质量：识别质量阈值，不属于毫米级边界。头部/腕部仍互补、仅判断大体关系；缺失数据不能伪称成功。
- `assert_goal`精确关系、是否同一三维点/路径、近零计算阈值：内部生成数据的代数一致性，并非实物测量精度要求，保留。

## 执行与恢复

未把失败回执改成成功，也没有自动重放已执行动作。本版只是让下次按当前实测状态检查同一条路径时使用一致的容差。原生拒绝在Web显示为 `Planning/geometry refusal`，不再误报成缺少图片。安装后不自动启动任务或回零。
