## 几何方法及限制

- 夹爪是平移关节，运动轴与开度倍率由正在使用的URDF读取。每根手指起点和终点包络的包围盒覆盖中间全部张爪过程，不只检查TCP或开度端点。后端仅增加只读几何元数据，未修改模型资产、控制参数或FCL。
- 使用已安装140mm TCP /170mm指尖模型。积木按约60mm的直立方块建模；XY用可包住任意平面旋转的外接方形，避免假设积木轴向与机器人完全一致。
- 指尖与积木沿任一空间轴有足够分离即可；接近、重叠、碰桌仍拒绝。20mm标定余量不删除。张爪之后仍需原生CAD/工作区预检通过。
- 机械臂运动仍是原有的FK离散采样加原生路径检查，没有宣称连续机械臂轨迹或完整环境碰撞认证。桌外未知物体和线缆不在这份积木模型中。
- 始终使用同一轮的目标、模型版本和控制归属；模型缺少夹爪运动轴时返回具体错误，不猜开合方向。

## 本次门槛审查中保留的约束

这些不是仅由二维外观代替空间判断的门槛，不能统一删除：

- 关节/夹爪范围、400mm单次位移、60°关节段、IK、自碰撞、工作区和到位容差。
- 帧新鲜度、Owner身份、几何/标定哈希、已完成回执、跨遮挡目标来源，防止旧图和另一轮状态被当作当前事实。
- 真实深度有效样本、平面覆盖/倾角、目标高度一致性；它们用于建立三维坐标，不是成功与否的像素评分。
- 插入、带载、支撑与释放的动作边界：夹持开度、支撑面关系、不能向桌面下方下压、与邻块分离、当前抓取姿态。新增图片搭法或自动换抓取方向仍未实现。
- 试抬和最终结果中的颜色/相对位置规则仍是定性证据；明显消失/移动不能无条件通过。当前已有阈值仍可能在未见过的遮挡下返回unknown，不能把本次修改说成全部视觉泛化已解决。

## 离线证据

- 本次真实失败帧：旧规则因红块水平距离82.6mm<90mm拒绝。新规则给出的最小积木分离下界95.9mm、桌面净余量153.9mm（均扣除20mm标定余量），且原生FCL/工作区通过。不是实际测得的接触力或真机验收。
- 36次运动轴预测与真实URDF开度FK对照，最大角点误差约9.21e-10m。
- R8三个原始空载过渡离线回放通过，新三维检查与原生FCL/工作区均通过。
- 新增碰桌、实际重叠、中途障碍、缺失运动模型、原生路径拒绝、像素诊断和具体错误保留测试。

Web接入新可写候选，默认Gemini关闭、不调用主Agent。下一次测试仍从Prepare和新的初始定位开始，不会自动重新执行失败轮次。
