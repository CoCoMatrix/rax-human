# C-0.3.4：正上方优先的接近候选

保留 C033、原版与冻结控制器；仅在独立候选中修改 assembly_plan.py。

候选顺序：既有正上方悬停 → 按真实指尖、局部桌面与原生桌面包围盒算出的较低正上方位 → 沿手指长度方向向内/另一侧偏移10mm的低位入口。末段保持原有接触走廊，不把偏移入口扩大成任意斜向接触。

源位置提前筛选只检查必要的抓取位。不能因为同XY上方悬停无解就淘汰全任务。接近路径仍通过完整几何、原生FCL、工作区检查；只在完整任务候选全部通过后允许执行。低位路线的过渡高度根据障碍物生成，不继承上一动作的退开高度；扩大有限门户候选，不改变碰撞距离。

同样修正出场：保留既有较高抬升优先，当该列上方空间的IK不可达时，根据负载/桌面算较低的离桌点，再向内搬运。原有10mm以下禁止横移的规则、载荷最低间距、姿态和原生检查均保留。新增短抬升候选用抓取关节解作种子。闭爪/释放边界不合并。

数值控制契约保持C033：50%速度；关节跟随0.1rad，到位/绑定0.01rad；普通夹爪完成3mm，接触闭爪48–54mm；夹爪绑定与持稳不变。宿主接口没有修改，沿用C033已验收的35项接触完成契约证据。

本次验证：419项回归与52子测试；20组完整规划/原生检查/衔接曲线验证；本次失败摆位使用Web实际隔离环境，分别无额外延迟和每工具调用增加4ms回放。报告保留准确耗时、IK/FK次数和候选选择。均为离线结果，未启动真机、相机或模型请求。
