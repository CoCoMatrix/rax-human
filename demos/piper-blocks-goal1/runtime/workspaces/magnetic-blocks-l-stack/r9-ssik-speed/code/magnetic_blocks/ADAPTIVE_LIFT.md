## 选择方式

1. 从当前实测关节、已完成试抬/搬运回执、同次抓取关系计算负载底部偏移。
   保留三维目标的现有来源、状态绑定和遮挡复用规则。
2. 结合后续搬运走廊中的积木高度、现有 20 mm 负载离障要求和 5 mm
   规划余量，计算候选高度区间；同时受当前 workspace、单段升高
   5–100 mm 和放置段能力约束。2.5 mm 是搜索分辨率，不是到位容差。
3. 从较低高度向上搜索。每个候选都调用同一原生 IK、安装指尖碰撞、
   workspace 和采样负载包络检查。橙色还验证横移、两段下降、退开；
   绿色第一次抬升还验证下一横移、第二次抬升和最终放置路径。
4. 找不到可行组合就报告候选拒绝原因；不改成任意固定值，也不在
   网络/控制不确定时继续试。选择函数没有动作或模型调用。
5. 预测的关节路径不是实测状态或动作回执。真正执行仍绑定当前反馈，
   原函数重新检查实际状态、路径及必要的夹持/支撑事实。
