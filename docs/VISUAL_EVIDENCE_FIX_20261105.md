# 视觉证据职责修复 — 2026-11-05

本次修复部署到 5090 的 v0.3 可写工作副本；没有启动机器人、相机 owner 或真机动作。冻结 v0.1/v0.3 保持不变。保留 RAX 原生 autonomous-control 逐函数流程和 request_operator，不新增控制框架。

## 根因与修复

- 空载准备检查不再要求看见全部隐藏爪底，也不要求两张端点照片证明动作期间从未短暂接触。只读定位不再附带空爪/接触间隙前置条件。
- 头部与左腕一起判断具名事实；一个相关视角的清晰证据可以解决另一视角的投影重叠。无关遮挡不自动变成运动前提。数值位姿、到位和已建模碰撞由几何/控制接口检查。
- 之前现场回复只是拼入问题，仍然要求相同事实被图片证明。现在视觉事实和人工事实分别保存来源；隐藏事实仍是视觉 unknown，不伪造 supported。
- 真正必要的未知事实返回一个范围明确的原生 request_operator 请求。恢复时从 host 按 request_id 读取原始回答，检查原问题、owner、姿态、动作和几何版本；不能用可写 JSON 中的伪造答复代替。
- empty_open、stage、approach 正确传递 operator_file 等选项。现场事实在派发前一次性消费，不用于动作之后；动作后检查失败只观察，不重放。
- 模型等待后重新检查 owner generation 和实测状态。可见危险、矛盾、否认或不确定答复、姿态/场景改变仍会阻止动作。
- 真实 API 回放发现模型引用前缀和前后帧标签不合契约；已明确 exact quote 和 before/current 字段格式，没有放松校验。
