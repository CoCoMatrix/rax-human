# v0.3 函数化准备与过渡姿态

本次仅修改工作副本及杯子任务说明，冻结版本不变。

`rehearsal.prepare_for_approach(ctx,{})` 从新定位和实测 FK 计算杯外等待位置、向下姿态和夹爪开合轴。函数内部执行有界普通 Python 循环，主 agent 不再逐次选 delta 或尝试位移值。它不是 XPolicy 的 Prepare/回零，也不含抓取动作。

- 目标为杯壁外侧100mm、法兰高度由杯沿高度及140mm TCP计算；先抬高低位法兰，再作有界旋转/平移。参数仍需真机演练验证。
- 每个候选不超过55mm平移、35度姿态变化；每次调用最多10个动作。
- 由现有 MoveIt IK 求解、现有路径检查判定，执行同一组已检查的关节目标。没有新增求解器、状态机或框架。
- 只有明确未派发的 MOVEIT_NO_IK_SOLUTION 可转到不同候选；未知错误或执行失败即返回，不自动重放。
- 准备过程刷新定位与状态，位置变化大于20mm停止检查，不追逐变化的目标。所有原有权限、到位容差、几何身份检查保留。
- preparation parent report记录总耗时、视觉/运动/规划耗时、visual_calls、ik_calls和子步骤。子记录不能与父记录重复累计。
