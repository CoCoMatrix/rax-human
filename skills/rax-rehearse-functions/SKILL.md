# RAX 逐函数演练

把成功探索变成可复用的 `fn(ctx, inputs)`，先逐函数验证，再交付组合 `main(ctx)`。**演练由主 Agent 组织；Gemini 是按需调用的感知工具。** 不因减少模型等待而跳过函数结果检查，也不把每个前置条件都翻译为一次图像问答。

本 skill 保存的是 2026-11-10 核对的 Piper v0.4 方法，不附带完整控制后端。安装或读取它不启动机器人。参数是这台设备的选择，换设备先核对工具契约和实测能力。

## 主 Agent 负责生成与收尾

经验提炼、函数代码生成/修复、相关离线验证和 Git 版本保存由 **RAX 会话主 Agent** 完成；Mac 正常负责监督、核验和归档。已有 Mac 候选可保留来源后复用。探索成功后的阶段停止不应取消软件收尾，也不自动授权下一轮真机动作。

新任务启动、分工纠正或预算收尾，读 [主 Agent 责任、预算和交付](references/agent-ownership-and-closeout.md)。只更新后续新会话，不修改正在运行的演练。离线通过、已提交版本与真机函数通过分别记录；收尾单独运行，不占探索／演练预算；出现阻塞时保存 partial，不让宿主代填成功控制器。

## 开始时只读必要资料

先定位用户指定的可写工作副本、代码 commit、当前会话和实测状态。读取当前任务简报、函数签名、上一阶段紧凑报告及下一函数所需经验；问题指向源码时再展开对应实现。不要启动即通读所有放置、感知源码或反复压缩同一资料。

- 组织演练、恢复或确认 Franka 原意：读 [原生演练与函数入口](references/franka-rehearsal.md)。
- 对照当前 Piper 参数、备份及旧入口：读 [v0.4 配置与版本身份](references/piper-v04-snapshot.md)。
- 排查重复定位、遮挡或过严检查：读 [视觉与深度方法](references/vision-and-depth.md)。
- 调 Gemini 或排查代理长尾：读 [Gemini 接口](references/gemini-interface.md)。
- 验证改动、比较耗时及收尾：读 [问题、证据和验收](references/failures-and-validation.md)。

## 执行顺序

1. 从已保存的成功策略和关键帧提取一个有用子目标，核对是否含人工帮助。冻结版本只读；在独立可写副本修改并记下来源。对当前项目，先核对 `controller.py` 的实际 imports，避免调用同名旧函数。
2. 函数接收同一 `ctx` 和明确输入，检查前置条件，完成有界动作，返回 `ok`、实测值、原因、报告路径、是否已经运动及耗时。正常小分段在函数内完成，不每段返回 Agent 重新规划。
3. 在本轮现场授权和设备所有权成立时，通过 RAX 原生会话调用该函数；检查紧凑报告和相关观测，异常再读取对应源码、录像或完整日志。仅做离线工作的请求不得变成真机验证。
4. 普通代码、当前控制反馈及几何处理可计算条件。任务视觉只处理可见事实；只有普通规则不足或发生相关异常时才调用 Gemini。不要要求照片证明隐藏爪底间隙或两帧之间从未接触。
5. 修复后先回放相关证据及反例，再从当前实测状态重入单个函数。动作回执与感知失败分别处理；已经试抬而视觉失败不等于没有抬起，不能盲重放动作。
6. 函数逐一通过后保存代码、参数、阶段耗时、主 Agent/辅助视觉次数、问题和人工帮助。备份演练副本，再将相同函数组合到 `main(ctx)`，进入新摆位整段测试。没有完成的函数明确记为待验收。

## 需要保留的边界

- 新摆位必须重新自动定位；同一次有界接近的有效三维目标可跨函数和预期遮挡保留。旧像素不能直接索引新深度图。
- 复用同一边界已证明的事实，不自动把它扩大为另一条路径的批准。物体移动、身份不明或会话/几何变化时重新建立关联。
- 头部承担已标定的度量定位；腕部 RGB 补充夹持关系。无手眼标定的腕部 FFS 点只在相机坐标内解释，不能直接生成基座运动目标。
- 接近、闭合、试抬、搬运、放下、释放和退开保留可恢复边界。异常可触发有界只读重观测；未解决的物理矛盾不能靠重复问模型直到通过。
- XPolicy 原生 Prepare 与任务内 `prepare_for_approach` 不同。回零走已有 XPolicy 入口，是否回零按本次用户指令和实际持物状态处理。
- 中断脚本不保证已下发运动取消。停止/恢复沿用原生 owner 和工具契约，核对回执与当前反馈；不增加另一个控制框架。

## 完成后的交付

交付可写代码版本、逐函数记录、尚未验证的范围及恢复入口。把人工事实补充标为辅助演练；不要计作无人介入成功。后续可使用 `rax-compose-and-test` 组织合并与规模测试；本 skill 自身是 Codex 工作指导，不等于已经通过 RAX `skills-lib` checker 的可执行机器人技能。
