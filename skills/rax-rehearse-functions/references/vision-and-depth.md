# 视觉、深度和少调用方法

## 每种证据回答它能回答的问题

| 条件 | 首选证据 | 不能据此推断 |
|---|---|---|
| 到位、状态变化、持稳 | 当前关节/夹爪反馈、FK、真实动作回执 | 夹爪达到目标不等于一定夹住杯子 |
| 数值路径与已建模碰撞边界 | 当前安装几何、环境模型、IK/FCL、工作区检查 | 自碰撞通过不等于未建模环境无障碍 |
| 初始杯沿、杯垫度量位置 | 本轮头部 RGBD、有效深度、内外参及轮廓 | 单个噪声像素或模型生成的 XYZ 不是可靠三维测量 |
| 头部遮挡后的夹持关系 | 左腕橙垫、杯壁区域及前后关系 | 像素投影重叠不等于物理接触 |
| 是否明显滑落、歪倒或错位 | 当前头部/腕部可见事实，必要的前后比较 | 看不到杯底不能自动判定没抬起 |
| 动作期间短暂接触/滑移 | 录像、控制状态及适当传感器 | 两张静态图片不能证明期间从未发生 |

旧失败把“隐藏爪底与桌面有多少间隙”“两帧之间从未接触”交给图片判断，导致空载准备也停住。修复是把条件拆到对应证据，不是无条件将 unknown 改为 pass。

## 新摆位自动定位，同一次接近保留目标

1. 每轮用新的观测定位杯子和杯垫，不手动输入摆位，不用上轮坐标。
2. 当前 `localize_supported` 先尝试当前轮廓、局部跟踪和有效深度；关联不明确才用 Gemini 语义定位。Gemini 给出语义/归一化图像位置，普通代码再与当前轮廓和深度关联，不能直接采信模型生成的三维坐标。
3. 语义请求耗时导致原深度过期时，有界刷新当前 RGBD，核对相机内外参、状态和身份，用新轮廓、新深度重新测量。不是修改时间戳，也不是旧像素直接读取新深度。
4. 目标保存来源帧、坐标系、标定/几何身份、owner/bridge、预期状态及阶段，供本轮函数使用。同一次有界接近中，预期机械臂遮挡不要求重新测一次近侧杯沿。
5. 物体实际移动、关联丢失、异常接触或会话/标定更换时，原目标的适用条件失效；重新定位或返回明确异常。正常静止目标的记忆与“新鲜控制状态”分别管理。

这同时解决了两种浪费：重复让模型识别全部物体，以及已知目标被遮挡时反复等待不可能得到的新深度。

## 当前 main 所用函数的取图安排

| 阶段 | 正常路径 |
|---|---|
| 初始准备 | 获取新的初始 RGBD 和所需视角，建立杯子/杯垫目标；语义定位按需 |
| 空载过渡、hover、entry | 当前反馈与数值路径检查；普通小段不重复下载三路 JPEG、不固定问 Gemini |
| 闭合 | 沿本轮已验证接近目标，检查当前状态和实际闭合结果 |
| 40 mm 试抬 | 获取有意义的前后证据；普通规则判断定性夹持，必要时辅助视觉 |
| 搬运 | 使用本轮初始杯垫目标与实测拾取变换，不再重新语义定位杯垫 |
| 放下 | 当前同轮目标路径按初始高度差计算下降；不在接近支撑高度时反复取图 |
| 释放、退开 | 检查开度与动作回执，最后一次观察定性放置结果 |
| 异常 | 针对缺失事实补充观察/模型请求；不把异常路径变成每阶段固定步骤 |

数值动作可设置 `observe_after=False`，仍保留状态和回执元数据。该策略针对当前 `scheduled.py` 及 `trial_lift(..., execution_mode='task_scheduled')`；旧函数仍可能带额外图像检查。

当前放下高度使用 `entry_flange_z + initial_coaster_z - initial_table_z`。这依赖本轮目标、桌面/杯垫高度关系和未明显滑移的拾取状态，是用户选择的任务策略。称为预测放置高度，不伪称测到了支撑力；遇到可靠的滑落、错位或接触异常时不能机械套用。

## 普通规则 → 必要深度 → Gemini

`checks.assess` 汇集要求的事实，先调用普通规则；只对尚未解决的事实请求有实际消费区域的腕部 FFS，仍不足才调用辅助视觉。模型调用按同一边界去重，记录每个事实的证据来源。

- 试抬至少 40 mm，更利于前后比较。实际 FK 抬升、夹爪开度、杯体相对橙垫仍大体保持、没有明显滑落/歪倒，以及可靠头部高度变化共同提供定性证据；阴影变化只能辅助，不能单独证明夹持。
- 两侧橙垫被部分遮挡会改变可见质心。使用共同可见区域和中间杯壁关系，避免把几像素偏差当作抓取失效。
- rc9 让腕部定性夹持规则独立于头部精确杯沿深度有效性；头部精密深度缺失不阻止腕部给出有依据的结论。可靠头部高度若明显矛盾仍需处理。
- 当前规则的部分数值适用范围为：试抬实测约 30–65 mm、夹爪反馈约 2–6 mm，再结合图像关系。它们是本机普通规则的范围，不代表这些数值单独足以证明抓取。
- 放置优先结合真实释放/退开回执和当前杯子大体处于杯垫位置的视图。允许定性判断，不要求所有隐藏接触面精确可见；也不把遮挡下的未知状态描述为已测量接触。

普通规则失败时区分“没有足够观测”和“有可靠矛盾”。明确失败原因后再选兜底，不因为模型尚可调用就先调用。

## 头部与腕部怎样联合

通常联合头部和左腕；右腕可在身份混淆或有关事实需要时使用，不必每个请求上传三张图。右爪与左爪必须在描述中区分。

已有 0.25 s 的近同时判断被两路异步取图频繁触发。改进保留两种合法证据：近同时帧，或**同一个已验证静止区间**内的有效帧。后者仍检查图像年龄、owner、状态绑定及期间没有动作，记录 `pixel_fusion=false`；不把不同时间的像素当同步几何融合。移动期间、长暂停或身份变化不能套用这个放宽。

左腕 FFS 已可产 optical-frame 深度；没有手眼外参时可辅助局部深度关系/质量判断，不能将该点直接变成基座 XYZ，也不能独立证明爪底到桌面的全局间隙。无有效杯壁/橙垫 ROI 或结果没有消费者时，不发 FFS 请求。

## 同一动作边界复用与模型提问

上一步后观测和下一步前条件可共用一次新观测，前提是状态、owner、几何、上次动作和图像身份仍匹配，且没有介入动作或长暂停。仅复用允许且已证明的夹持/支撑/空爪等事实；上一帧“有间隙”不批准另一条运动路径。

给 Gemini 的每幅图紧邻标注：current/before、camera、frame ID、实际传输宽高。当前图优先；前后比较需要时才带历史图。归一化像素只换算一次，不用缩略图坐标再重复缩放。简单 RGB 判断不强制等待不需要的深度。

提问示例：“比较 before 与 current，杯体与橙垫的相对夹持区域是否大体保持？是否出现明显滑落或歪倒？只报告可见证据，遮挡记 unknown。”避免询问隐藏的毫米级间隙、完整扫掠路径或整个时间区间无接触。

人工事实、几何结论和视觉结论分别保存。一个视角看不见并不否定另一个清晰视角；总的 `ok=true` 也不能覆盖关键事实仍为 unknown 的情况。
